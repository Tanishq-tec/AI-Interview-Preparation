AI Interview Preparation

📌 Overview
AI-Interview-Preparation is a LLM-based project designed to help learners practice interview scenarios with an AI-driven 
dynamic bot. The bot simulates real interview interactions, generates questions, and adapts its flow based on user-
responses.

This repository is ideal for students, job seekers, and professionals who want to sharpen their interview skills in a safe, interactive environment.

Features
Dynamic interview Q&A flow.
Customizable question sets for different domains (Data Science, Web Development, etc.).
Real-time response handling.
Lightweight and beginner-friendly Python implementation.
Extendable for integration with APIs (OpenAI, LangChain, etc.).
